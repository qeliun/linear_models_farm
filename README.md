# Прогноз удоя и вкуса молока для фермерского хозяйства

Учебный проект по машинному обучению для молочного хозяйства «Вольный луг». Фермер планирует приобрести новых коров и хочет заранее оценить, какие животные соответствуют его требованиям по годовому удою и вкусу молока.

## Задача

Построить две модели:

- регрессионную — для прогноза годового удоя;
- классификационную — для оценки вероятности получить вкусное молоко.

Коровы рассматриваются для покупки, если ожидаемый удой составляет не менее 6000 кг в год, а молоко соответствует вкусовым требованиям фермера.

## Что сделано

- объединены данные о коровах и их родословной;
- обработаны дубликаты, опечатки в категориях и аномальное значение удоя;
- проведён исследовательский и корреляционный анализ;
- подготовлены числовые и категориальные признаки;
- добавлены преобразования для нелинейных зависимостей;
- сравнены три модели линейной регрессии;
- рассчитан 95%-й интервал прогноза удоя;
- построена логистическая регрессия для прогноза вкуса молока;
- подобран порог классификации с учётом высокой стоимости ложноположительной ошибки;
- сформированы рекомендации по покупке коров.

## Результаты

Лучшая регрессионная модель показала:

| Метрика | Значение |
|---|---:|
| R² | 0,87 |
| MAE | 159 кг |
| RMSE | 193 кг |
| Покрытие 95%-го интервала на тесте | 94% |

Для классификации выбран строгий порог, позволяющий избежать ложноположительных прогнозов на тестовой выборке. При этом полнота модели остаётся низкой: модель пропускает значительную часть подходящих коров. Это ограничение учтено в итоговых рекомендациях.

Из 20 предложенных коров три прошли оба критерия с учётом нижней границы интервала удоя. Ещё четыре коровы подходят только по точечному прогнозу и требуют дополнительной проверки перед покупкой.

## Запуск

1. Клонировать репозиторий.
2. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Поместить `ferma_main.csv`, `ferma_dad.csv` и `cow_buy.csv` в папку `datasets`.
4. Открыть `linear_models_farm.ipynb` и выполнить все ячейки.
